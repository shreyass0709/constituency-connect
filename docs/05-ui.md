# 05 — UI: Design System, Wireframes, Component Hierarchy

## 1. Design language

The bar is Linear/Stripe polish, but the audience is a citizen on a mid-range Android
phone — so: generous type, high contrast, obvious tap targets, and warmth. Premium
comes from restraint + motion discipline, not decoration.

- **Typography:** Inter (UI) + Bricolage Grotesque (public-site display headings). Scale: 12/14/16/18/24/32/48. Body 16 px minimum on mobile.
- **Color tokens (CSS variables, shadcn theming, light + dark):**
  - Brand: deep civic indigo `--primary` (light `#3F51E0` / dark `#7C8AFF`); warm saffron accent for the public site's "action" moments.
  - Status colors (single source: `constants/status.ts`): DRAFT slate · SUBMITTED blue · ACKNOWLEDGED cyan · ASSIGNED/DEPT_REVIEW violet · FIELD_VERIFICATION/IN_PROGRESS amber · COMPLETED lime · CLOSED green · REJECTED red · REOPENED orange. Priority: LOW gray, MEDIUM blue, HIGH amber, URGENT red.
- **Surfaces:** rounded-2xl cards, 1 px borders, soft shadows; glassmorphism only on the public-site hero and sticky headers (blur + translucency) — never on data-dense admin surfaces.
- **Motion (Framer Motion):** 150–250 ms ease-out; page fade+4 px rise; stagger lists 30 ms; animated number count-ups on Action Dashboard; timeline entries slide in; `prefers-reduced-motion` disables all of it.
- **Dark mode:** class strategy via next-themes; both themes tuned, not auto-inverted.
- **Micro-interactions:** button press scale 0.98, optimistic checkmarks, copy-code button on complaint code, confetti (once) when a citizen's complaint is resolved.
- **States, mandatory for every list/detail:** loading skeleton (`Skeleton` matching final layout), empty state (illustration + one-line + primary action), error state (retry button), offline banner for field PWA.
- **Feedback:** sonner toasts bottom-right (desktop) / top (mobile); destructive actions get AlertDialog confirms.
- **Command palette (cmdk):** `Ctrl/⌘+K` — navigate, search complaints by code/title, quick actions per role. Shortcuts: `g d` dashboard, `g t` triage, `c` new complaint, `/` focus search, `?` shortcut help.
- **Accessibility:** every interactive element keyboard-reachable; focus rings visible; form errors announced (`aria-live`); icons always paired with text or `aria-label`; color never the only signal (status chips carry text).

## 3. Component hierarchy

```
RootLayout (fonts, ThemeProvider, ToastProvider, QueryProvider, CommandPalette)
├─ (public)/layout — PublicHeader (glass, lang switch) · PublicFooter
│  ├─ HomePage = Hero + ActionStatsRow(StatCard×n) + TransformationMap + StoryGrid + …
│  ├─ TrackPage = CodeSearchForm → PublicTimeline
│  └─ MapPage = MapView(+ MapFilters, PinPopup(BeforeAfterSlider))
├─ (auth)/layout — PhoneOtpForm · GoogleButton · OnboardingSteps
├─ AppShell (role-aware Sidebar/BottomNav + Topbar(NotificationBell, UserMenu, ⌘K))
│  ├─ (citizen) Dashboard(MyComplaintCards) · RaiseWizard(CategoryGrid, MediaUploader,
│  │            VoiceRecorder, LocationPicker, AiSuggestionCard) · ComplaintDetail(
│  │            StatusChip, SlaMeter, Timeline(TimelineItem), MediaGallery, FeedbackDialog)
│  │            · Appointments · Polls(PollCard) · Suggestions · Volunteer · Settings
│  ├─ (office) Triage(TriageTable, AiPanel, BulkBar, MergeDialog) · ComplaintsTable
│  │            (DataTable + FilterBar + ExportMenu) · SlaBoard · Analytics(ChartCards)
│  │            · Content editors · Admin(UsersTable, RoleDialog, WardEditor(MapDraw),
│  │            DeptEditor, SlaEditor, AuditViewer)
│  ├─ (department) Queues(Tabs+DataTable) · DeptAnalytics
│  └─ (field) TaskList(TaskCard, DistanceBadge) · TaskDetail(ProofCapture(GeoChip),
│             SignaturePad, OfflineQueueBanner)
└─ shared: DataTable (TanStack Table: sort/filter/paginate/column-toggle) · MapView
   (Leaflet wrapper: pins/heat/boundaries/picker modes) · MediaUploader (signed direct
   upload, previews, progress) · Timeline · StatCard · StatusChip · PriorityBadge ·
   EmptyState · ErrorState · Skeletons · ConfirmDialog · PageHeader
```

Rule: shadcn primitives in `components/ui` stay unmodified; composition happens in
`components/shared` and feature components. Recharts wrapped once in `ChartCard`
(theme-aware colors, skeleton, empty state) so every chart matches.
